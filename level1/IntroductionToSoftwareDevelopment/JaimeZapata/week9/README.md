Rama de Trabajo (feature/)
● Desde develop, crea tu rama de trabajo con la nomenclatura:
feature/nombre-apellido (ejemplo: feature/camilo-lopez).
● Todo el código, estilos y maquetación deben desarrollarse exclusivamente dentro de esta
rama. Queda prohibido trabajar directamente sobre master o develop.

Estándar de Commits
● Debes registrar un mínimo de 15 commits que reflejen un avance progresivo y coherente a lo
largo del examen (no se admiten entregas resueltas en un único commit masivo).
● Los mensajes deben ser descriptivos y utilizar prefijos convencionales (por ejemplo: feat:
para nuevas secciones o módulos, style: para reglas de diseño/CSS, fix: para correcciones
visuales, chore: para configuración o carga de assets).
